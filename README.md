## 怎麼玩

推薦先選第 3 章「撤離救護站」。護衛、偵察員、軍醫每回合各能移動並使用一個行動；先看敵方意圖，再安排掩護、煙幕、醫療、救援與撤離。目標是完成任務並保護小隊，不必清光所有訓練機。選取格子先預覽，確認後才執行；安全範圍內可撤回。

13 章皆可自由選擇，包含不同地形、守點、據點依賴與救援路線。新手「推薦下一步」可關閉，偏離推薦不扣分。戰後填「理由與教材依據」及「何時會修正」兩欄反思；勝利與失敗都能完成學習，不以單一道德分數評判選項。

六套精緻角色外觀、各角色獨立姿勢、13 張原創場景及簡短中文合成旁白已整合。造型不影響能力。13 章原創背景配樂使用 Web Audio，須操作後啟動；背景音樂與角色語音可分別關閉。保留 28 個可選支線／收藏互動，其中 15 道分類、相依排序或資源組合益智與 13 件彩蛋。

## 班級同步與出席

正式 v2 同步已啟用。開啟「班級同步」，在 Google 分頁以名冊授權帳號登入，核對班級／身分，並在兩個頁面分別同意。名冊保留 19 人，其中 8 人仍待教師補齊 Google email；名冊未補齊授權 Google email、或帳號不符合名冊者不能入班。帳戶與名冊的細節不放公開網站。

同意後，已封存挑戰、回合／終局快照、已完成的反思及可重播支線事件送往新版專用私人紀錄分頁。未完成反思草稿只留本機。斷線保留事件並以相同編號重送；僅收到精確對應的伺服器回執才顯示已收件。探索／收藏／解謎三榜只比較支線事件，不按戰鬥勝敗、反思文字或倫理選項排名。

**已收件仍待教師核實，不會自動算出席。** 原 u03 當堂手動收件保留，10/6 原定收件時段為台灣時間 13:30–15:20，依老師指定流程與私人課堂碼操作。新版勝敗不作出席門檻；不要把新戰棋 JSON 貼到舊版收件表單。

舊版遊戲及本機歷程保留在 `legacy-v1/`，不做有損移轉。舊版頁停止啟動全班自動同步，以避免舊多分頁綁定風險；舊已收件歷史與後端 v1 查詢仍保留。新增「下載舊待同步備份」只保存原始本機佇列，不傳送、不改動原資料，也不代表已收件。原 `#classroom-receipt` 書籤會前往舊版收件入口。

## 儲存與部署邊界

正式、試玩、舊遊戲與同步佇列各用獨立儲存鍵。匯入須驗證並確認，會撤回同步同意，之後要重新核對身分。每次失敗／重試保留獨立挑戰；伺服器用凍結的引擎及內容嚴格重播，不把新版偽裝成舊版六指令。

同步需要支援 Web Locks 並取得本頁寫入鎖。另一分頁持鎖或瀏覽器不支援時仍能本機遊玩與下載，但不能同步。Google 權杖只留 Google 分頁記憶體，公開遊戲不存權杖。沿用既有 OAuth 與權限，不擴大 scope。

Google 正式收件器目前為乾淨不可變 v5，同步旗標已開啟。此公開 repo 的 `collector/` 是保留的舊版 u03 手動收件原始碼，**不是目前完整 v5 部署包，不可直接覆蓋正式 Google 專案**。新版完整後端另外保存在教師私人原始碼備份，公開網站不含名冊、工作表 ID、密鑰或 QA 管理程式。詳見 [正式版說明](TACTICAL_FORMAL_RELEASE_NOTES.md)。

## 驗證與建置

Node 22 以上，無第三方 npm 執行套件：

```sh
npm test
npm run build
```

目前完整前端／舊版回歸套件 586 項通過，含 13 章共 26 條通關路線、回放、存檔、技能資源、反思、回執、離線重送、同意撤回、帳戶綁定與分頁生命週期。GitHub Actions 只部署 `scripts/build-site.js` 明確清單，不部署後端、測試、教材、備份或學生檔。實際發布結果以該 commit 的 Actions 為準。

另已實際驗證正式 GitHub → Google 的來源／nonce 橋接、斷線回應、非名冊登入拒絕，以及三筆合成 v2 QA 的寫入、讀回、重播、去重和限流。QA 不算出席或正式排行。名冊學生本人 Google 登入及正向送件仍待本人實測，不以教師帳號冒充；桌機內 390/320px 版面驗收不等於實機觸控。合成旁白經模型逐字與音訊技術核對，未聲稱真人配音或真人聽感驗收。

## 素材與教材

新版精緻人物、場景以 Google Flow / Nano Banana Pro 及透明背景處理流程製作；不是宣稱使用 Imagen 2.5。姿勢為分別製作的靜態圖，搭配移動／攻擊／命中特效。中文旁白採原生合成聲線；章節 BGM 為原創 Web Audio 樂曲。舊素材來源保留於 `assets/rpg/README.md`，系統字型不隨 repo 散布。

章節只帶摘要與來源頁碼，不包含教材 PDF，沒有將教材或第三方素材重新授權為 MIT 等開源授權。請勿提交姓名、學號、反思、工作表 ID、憑證或任何學生匯出檔。
